# Pipedrive MCP Integration with Claude

## Recent Project Overview

Automated Sales recently developed a custom **Pipedrive MCP integration for Claude**, giving users a conversational way to ask questions about their CRM data.

The project connected Pipedrive with Claude through a custom Model Context Protocol setup, allowing Claude to retrieve relevant CRM information and provide useful, plain-English answers about deals, activities, organisations, contacts and pipeline performance.

This gives sales teams a faster way to understand what is happening inside Pipedrive without needing to manually filter CRM views, build reports or export data into spreadsheets.

---

## The Challenge

Pipedrive is an excellent system for managing sales pipelines, but many businesses still find it difficult to quickly answer commercial questions such as:

- Which deals are at risk?
- Which opportunities have had no recent activity?
- What changed in the pipeline this week?
- Which deals are most likely to need follow-up?
- Which accounts have recent activity?
- Where are deals getting stuck?
- What should the sales team focus on next?

These questions can often be answered inside Pipedrive, but doing so usually requires the right filters, reports, exports or manual investigation.

The goal of this project was to make CRM data easier to explore by allowing users to ask Claude questions in natural language.

---

## The Solution

We created a custom MCP connection between Pipedrive and Claude.

This allowed Claude to interact with selected Pipedrive data and return structured, useful responses to sales and reporting questions.

Instead of manually searching the CRM, users can ask questions such as:

- “Which open deals have no upcoming activity?”
- “Show me the largest opportunities currently in the pipeline.”
- “Which deals have been sitting in the same stage for too long?”
- “Summarise recent activity for this organisation.”
- “Which deals were added this week?”
- “What are the main risks in the current pipeline?”

Claude can then use the connected Pipedrive data to return a clear summary, helping users understand what is happening and where action may be required.

---

## What We Built

The project included:

- A custom MCP server connected to Pipedrive
- Integration with Claude for natural language CRM queries
- Access to relevant Pipedrive objects such as deals, people, organisations and activities
- Structured responses for pipeline, deal and account-level questions
- A foundation for future AI-powered CRM workflows
- A practical way to turn CRM data into conversational insight

The integration was designed so that Pipedrive remains the central source of truth, while Claude provides a more flexible and accessible way to interrogate the data.

## Example Use Cases

### Pipeline Review

Claude can help summarise the current pipeline, identify high-value opportunities and highlight deals that may need attention.

### Stale Deal Identification

The integration can be used to identify deals with no recent activity, no next step or long periods in the same pipeline stage.

### Account Summaries

Users can ask for a summary of recent CRM activity linked to a specific organisation, contact or opportunity.

### Sales Manager Support

Sales leaders can use Claude to ask commercial questions about pipeline movement, open opportunities, activity levels and follow-up priorities.

### CRM Data Exploration

Instead of relying only on pre-built reports, users can explore Pipedrive data conversationally and ask follow-up questions as new insights emerge.
